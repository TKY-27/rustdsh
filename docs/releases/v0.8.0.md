## 0.8.0 — 初期セットアップの導線と、GPUI 製ネイティブ・デスクトップアプリ

- **ネイティブ・デスクトップアプリ（GPUI）を追加**: `apps/rdsh-desktop` は、上流 DeepSeek Harness のデザイントークンと HTTP / WebSocket プロトコルをそのまま使う Rust / GPUI のウィンドウです。Electron も同梱 Chromium もローカル Web サーバーも使わず、プロジェクト別サイドバー（実タイトル）、プロバイダ別モデルピッカー、ライブ差分表示と停止、承認・質問への応答、ツール呼び出しと推論の行、新規会話を備えます。`cd apps/rdsh-desktop && cargo run --release` で起動でき、`--dump-ui` / `--dump-titles` / `--probe` / `--dump-live` は同じデータをヘッドレスで確認します。Linux は Wayland / Vulkan バックエンド（ビルド時に xkbcommon と xkbcommon-x11）、Windows と macOS は GPUI の既定機能を使います。**この版の配布アーカイブにはまだ含まれず、ソースからのビルドのみ**です（#752、#765、#771、#776）。
- **初回セットアップウィザード**: `rdsh setup --web` が「確認 → AI 接続 → 完了」の3ステップになり、保護されたローカルの起動ファイル経由で開くため、**トークンは argv にも端末にも出ず、貼り付けも不要**です。Node.js・dsh・Codex・OpenCode・デスクトップアプリを検出し、見つかった Codex / OpenCode のログインをワンクリックで共有（永続化した `--select SOURCE:CREDENTIAL --import` の経路）し、`codex login` / `opencode auth login` を新しい端末ウィンドウで開始し、DeepSeek / OpenAI / Anthropic の鍵を保存して、最初の会話（デスクトップアプリ、`rdsh tui`、Web プロファイル）を起動します。トークン貼り付け欄はフォールバックとして残ります（#753）。
- **インストーラからウィザードへ**: 対話インストールの完了後にウィザードを開きます（`install.ps1 -NoSetup` / `install.sh --no-setup` と `CI` は開きません）。Windows では dsh が無いとき `npm install -g @deepseek-ai/dsh` を案内し、スタートメニューに「rdsh setup」を追加します（#753）。
- **プロジェクトダッシュボードの簡易表示**: 既定を「いまの状態・人が待っていること・エージェントの画面・タスク・レポート」だけの簡易表示にまとめ、「くわしく表示 / Detailed view」で従来の全パネルに戻せます。日本語のシステムフォントスタックと落ち着いた字面、`prefers-reduced-motion` を尊重する控えめな動きに整えました（#738、#753）。
- **Command Code プロバイダ**: `rdsh provider add commandcode` が Command Code の Provider API（`https://api.commandcode.ai/provider/v1`、OpenAI 互換、`COMMANDCODE_API_KEY`）をプロファイルのルートとして登録し、`--discover` が `GET /models` を読みます。`docs/PROVIDERS.md` に対象範囲（Provider API、Go プランの `403 upgrade_required`、`/messages` のみの Claude モデル）を記載し、**ZDR は要件定義（`docs/ZDR.md`）のみで実装はまだありません**（#450、#484、#762、#763）。
- **設計思想ドキュメント**: `docs/PHILOSOPHY.md` と `docs/PHILOSOPHY.ja.md` が「なぜ上流 Node.js ランタイムを維持し、熱い境界だけを Rust で締めるのか」を、`docs/BENCHMARKS.md` の実測値（`dsh --version` 約88ms・ピーク RSS 約66MB、PreToolUse フック約2.0ms/呼び出し）と非目標を添えて説明します（#777）。
- **CLI のネイティブ化**: 静的アダプタカタログが Rust ネイティブへ移り、ダッシュボードのサーバーはダッシュボードを開始するときだけ読み込むようになりました（#699）。
- **プライバシーの既定値を変更**: `features.telemetry` と `features.discord` の既定が無効になりました。委譲した `dsh` には既定で `DSH_TELEMETRY_DISABLED=1` を渡し（`RDSH_TELEMETRY=on` で有効化、既存の環境変数は変更しません）、Discord Rich Presence も設定プラグインが `features.discord` と旧 `discord.enabled` を同期させます。範囲と限界は `docs/PRIVACY.md` にあります（#735）。
- **ダッシュボードの CSS 致命的不具合を修正**: 閉じ忘れた2つのルールで、ブラウザがスタイルシート末尾の約1,100行（ワークスペース・グリッド、アテンション受信箱、モバイル表示など）を捨てていました。バランスを保つ単体テストを追加しています（#753）。
- **その他の修正**: Set-Cookie 解析失敗時に署名済みセッション cookie をエラーへ出さない（#775）、Setup ウィザードの Windows 端末起動（`start` の空タイトル）（#753）、Windows の surface rename を EPERM で再試行し同時書き込みを分離（#759、#769）、dashboard の macOS worker 境界・Store PowerShell 別名の tray 起動・証拠ディレクトリの正規化・中断した Harness プロキシの後始末（#739、#756、#757、#760）、Windows ランタイム JSON 置換の再試行上限（#749）、`dsh-env` の `dangerouslyAllowAllBuilds` 判定（#748、#764、#773）、serial proxy の `Connection` 指定ヘッダ除去（#761）、doctor の Windows JS パスと pnpm 9 の案内（#734、#746）、`guard.deny` の上限（#745）、macOS `accept` 継承 flake（#780）、worker-git ベンチの標本 pin と操作別予算（dirtyPaths は Windows 30ms）（#778、#779）。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 で、0.7.0 から変わりません。配布アーカイブの構成も同じです。
- 会話とモデル応答は本家 DSH のままで、互換性は維持されます（DSH **0.2.0-rc.2**、**0.2.1-alpha.1**、**0.2.1-alpha.3** のランタイムを認識）。
- 移行作業は不要です。`rdsh.json` の既存キーや既定値は変わりません。CLI のオプションと既存ルートの挙動も 0.7.0 と同一です。
- **プライバシー既定値が変わりました**: `features.telemetry` と `features.discord` は既定で無効です。有効にしたい場合だけ `rdsh.json` で明示し、テレメトリは `RDSH_TELEMETRY=on` でも有効になります。
- **デスクトップアプリは同梱されません**: 配布アーカイブには含まれず、`apps/rdsh-desktop` を Rust 1.85 以上でビルドしたソース実行のみです。Linux のウィンドウには GPU 対応の Wayland セッションが必要で、xattr 0.2.3 が現行ツールチェーンでコンパイルできないため同リポジトリの vendored 実装を当てています。初回起動だけホストを起動して以降は接続を再利用し、`--dump-*` 系はヘッドレスで動きます。
- **ZDR は要件定義だけです**: `docs/ZDR.md` は保持しないルートの要件を定める文書で、ZDR モードの実装はまだありません。
- **セキュリティ修正**: デスクトップアプリが Set-Cookie 解析の失敗時に署名済みセッション cookie をログへ出していた経路を塞ぎました（#775）。
- ソースからビルドする場合は Rust 1.85 以上が必要です（配布バイナリの利用に Rust は不要）。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。

デスクトップアプリを使う場合（配布アーカイブには未収録）:

```sh
cd apps/rdsh-desktop
cargo run --release
```
